# 🖼️ Django Image Uploader

A simple Django web app that allows users to upload images through a form and displays the uploaded images on the homepage.

---

## 🚀 Features

- Upload images via a web form
- View all uploaded images on the same page
- Stores files in a media directory
- Clean and minimal UI
- Uses Django's `ImageField` and `ModelForm`

---

## 🧱 Tech Stack

- Python 3.13
- Django 5.2
- HTML/CSS (basic styling)
- SQLite (default database)
- Pillow (for image processing)
